# Metaman Dhyaan — Two Modes, One Device
Concept, not an official Meta product. Designed in Delhi.

**Why:** Elderly with dementia/Alzheimer's fall at night. 7 gadgets = 7 cables = tripping hazard. Portal needs learning. We need presence, not screens.

**Vibe Mode:** RGB projector ON, dancing lights for Gen Z
**Calm Mode:** Physical Mood Switch disables RGB for dementia calm

**Features:**
- Amber directional lights for fall prevention
- IR presence sensor, SOS slider with family alert
- QI2 15W wireless charger, 5HR battery backup
- IP54 chai & water proof, washable Meta cap
- Floating 12mm base, sealed acoustics
- Privacy-first, on-device processing, BLE 5.3, WiFi 6, Matter Bridge
